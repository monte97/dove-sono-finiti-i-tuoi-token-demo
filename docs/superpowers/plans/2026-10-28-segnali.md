# Cinque segnali dalle registrazioni — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `segnali.py` calcola, da una cartella di registrazioni, i cinque segnali di «Lunedì, in produzione» (D29) come li mostrerebbe un cruscotto: ritentativi per strumento, forme dell'albero, approvazioni di `valida`, risposte da copia vecchia, costo per richiesta (mediana e 95° percentile).

**Architecture:** Un modulo nuovo che importa `strati` e ne riusa `grafo`, `approva`, `token`, `costo`, `attr`. Una funzione per run (`segnali`), una per la popolazione (`cruscotto`), una che stampa. Ogni segnale dichiara lo strato minimo che lo rende misurabile: sotto quello strato vale `None` e la stampa dice quale strato serve. I segnali leggono solo gli span, mai `risposta` né `fattura`: è ciò che avrebbe un backend.

**Tech Stack:** Python 3.14, sola libreria standard più `strati.py`. Nessuna rete.

**Spec:** `0_Content/_talks/devfest-alps-2026/observability-agenti-otel-storia.md`, D29 e «Lunedì, in produzione» (minuti 31-34).

## Global Constraints

- I segnali si calcolano dagli span della registrazione; `r["strato"]` dice solo cosa era strumentato.
- Strato minimo: ritentativi 2 (gli archi; gli strumenti di dati compaiono dal 3), forme 2, approvazioni 3 (serve `gen_ai.tool.call.result` sull'arco), copia vecchia 4, costo 1.
- Approvazione = `strati.approva(risultato)`, la stessa regola di `misura()`.
- Costo per run = somma di `strati.costo(in, cache, out)` sugli span con token.
- 95° percentile: `statistics.quantiles(costi, n=20, method="inclusive")[18]`; con una sola run vale quella run.
- Raggruppamento per cartella e per modo (`guasto`, `sana`), come `--misure`.
- Test nello stile di `test_strati.py`: funzioni `test_*`, eseguite da `python test_segnali.py`.

## Review Focus

- Cartella con run di strati misti o senza alcuna run di un modo: niente divisioni per zero, il modo assente non si stampa.
- Run in cui `valida` non viene mai chiamata: `approva` conta 0 su 0 e non lo scambia per «non misurabile».
- Registrazioni dello spike A (variante `chiedi_verifica`, tag `spike-a-b`): non sono in `registrazioni/` e non vanno supportate; nessun test.
- Il costo dagli span deve coincidere con quello della fattura quando l'SDK strumenta tutte le chiamate: se non coincide, il segnale mente (test sul reale nel Task 2).
- I numeri del freeze devono essere coerenti con `misura()` (approvazioni e ritentativi di `cerca`): test sul reale nel Task 2.

### Task 1: segnali per run e cruscotto

**Files:**
- Create: `segnali.py`
- Test: `test_segnali.py`

**Interfaces:**
- Consumes: `strati.grafo(span) -> list[str]`, `strati.approva(str) -> bool`, `strati.token(s) -> dict|None`, `strati.costo(in, cache, out) -> float`, `strati.attr(s, chiave, altrimenti=None)`.
- Produces:
  - `MINIMO: dict[str, int]` = `{"ritenta": 2, "forma": 2, "approva": 3, "copia": 4, "costo": 1}`
  - `segnali(r: dict) -> dict` con chiavi `chiamate` (`collections.Counter` nome strumento → chiamate, dagli span `execute_tool`), `forma` (`" ".join(grafo)`), `verdetti` (`list[bool]`, uno per arco verso `valida`), `copia` (`bool`: c'è almeno uno span `cache.read`), `costo` (`float`). Ogni chiave vale `None` se `r["strato"] < MINIMO[...]` (per `chiamate` vale la soglia di `ritenta`, per `verdetti` quella di `approva`).
  - `cruscotto(regs: list[dict]) -> dict` con chiavi `n`, `ritenta` (`dict` strumento → run in cui è chiamato almeno due volte, solo strumenti con almeno una run), `forme` (`Counter` forma → run), `approva` (`tuple[int, int]`: approvati, verdetti), `copia` (`int`: run), `costo` (`dict` con `mediana` e `p95`). Un segnale è `None` se è `None` in almeno una run.

def test_segnali_di_una_run():
    g = sg.segnali(RUN)
    assert g["chiamate"] == {"cerca": 2, "leggi_programma": 2, "valida": 1}
    assert g["forma"] == " ".join(s.grafo(RUN["span"]))
    assert g["verdetti"] == [True]
    assert g["copia"] is True
    assert abs(g["costo"] - (s.costo(1000, 0, 50) + s.costo(2000, 1000, 100))) < 1e-12

def test_sotto_lo_strato_minimo_non_si_misura():
    g = sg.segnali({**RUN, "strato": 3})
    assert g["copia"] is None and g["verdetti"] == [True]
    g = sg.segnali({**RUN, "strato": 1})
    assert g["chiamate"] is None and g["forma"] is None and g["verdetti"] is None and g["costo"] is not None

def test_cruscotto():
    sana = {**RUN, "span": [x for x in RUN["span"] if x["nome"] != "cache.read"]}  # stessa run, senza copia
    c = sg.cruscotto([RUN, sana, sana])
    assert c["n"] == 3
    assert c["ritenta"] == {"cerca": 3, "leggi_programma": 3}
    assert c["approva"] == (3, 3) and c["copia"] == 1
    assert sum(c["forme"].values()) == 3
    assert c["costo"]["mediana"] == c["costo"]["p95"]

def test_p95_e_valida_mai_chiamata():
    senza_valida = {**RUN, "span": [x for x in RUN["span"] if "valida" not in x["nome"]]}
    c = sg.cruscotto([senza_valida])
    assert c["approva"] == (0, 0)          # misurabile, e zero: non None
    costi = [0.001 * i for i in range(1, 21)]
    assert sg.p95(costi) == statistics.quantiles(costi, n=20, method="inclusive")[18]
    assert sg.p95([0.5]) == 0.5

def test_strato_misto_rende_none():
    assert sg.cruscotto([RUN, {**RUN, "strato": 3}])["copia"] is None
